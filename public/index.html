Poll data refresh policy

Public APIs are available for exchange prices, but these forecasting and polling sources do not provide a stable, unauthenticated data feed here. The site reads the current data/snapshot.json on each refresh. Edit that file and redeploy to publish a new verified poll/forecast snapshot. It will never claim a cached poll is fresh simply because the refresh button was clicked.
